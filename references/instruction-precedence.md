# 影视级 SOP 项目指令优先级

## 当前主入口

本仓库视频任务以用户最新上传的 `film-sop-core/higgsfield-seedance-prompt-builder.md`（v4.4.2）为核心，先读取 `film-sop-core/AGENTS.md` 的辅助技能路由。此选择以用户指定的新包为依据，不以文件修改时间或“Seedance 2.0”字样判断新旧。

## 冲突处理

1. 遵守平台上层约束及用户明确要求；真实素材、验收状态、准确标签不得虚构。
2. 用户已确认的项目语言要求是默认简体中文视频提示词，台词和标签原样保留。这覆盖核心原文的默认英文，不要求先英文再翻译。
3. 视频编译、格式、光学、空间、节拍及独立提示词要求，以 v4.4.2 为准。每段独立提交时，必须写出本段所需人物、场景、光线、道具和当前动作状态；不得用“上一段”“同一间房间”“同一只柯基”等指代代替事实。真实引用只能使用本次提供并绑定的素材。
4. 新包四项辅助 Skill 按 `film-sop-core/AGENTS.md` 路由使用，不覆盖核心或用户要求。
5. 旧 `references/components/xiaotian-cinedance/` 仅作补充参考，不再默认完整加载。只有新包未覆盖且当前任务需要时才读取相关模块；与新版重复或冲突的模板、语言、节拍和导演规则不执行。
6. LIRA 图片资产设计、验收与真实引用绑定继续保留；图片规则不决定视频最终模板。

## 版本与历史边界

指令包版本不等于视频模型版本。未指定模型时保留 Seedance 2.0；用户明确选择其他版本时，先核实目标平台能力，不从 v4.4.2 名称推导 2.5、30 秒或增强编辑支持。未合并 PR 不作为 main 已生效能力。

旧组件原文与哈希、旧示例和历史评测作为历史资料保留，不视为当前主入口或新版模型运行成绩。引用旧示例时必须重新按新核心编译。核心文件原文保持不变。
