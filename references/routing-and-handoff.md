## 1. 路由判断

### 只加载LIRA

用户要人物定妆、角色表、场景概念图、关键帧、道具图、图片编辑、局部修复、材质修复或图片提示词时，只加载LIRA。不要附加角色表演和视频镜头调度。

### 只加载xiaotian-CINEDANCE

用户已经提供足够角色/场景参考和准确标签，或者当前视频镜头不依赖前置图片时，直接进入视频路线。不要为了流程完整重新生成资产。

### 顺序加载两者

以下情况运行完整路线：

- 用户明确说先做人物/场景/道具，再做视频
- 核心人物身份尚未锁定，跨镜头一致性会受影响
- 场景地理、关键道具或首帧必须由参考图控制
- 用户要求一份从图片提示词到视频提示词的完整生产包

两个组件必须顺序加载，不能同时独立输出互不相干的长文。

## 2. 阶段状态

每项资产只能处于以下一个状态：

- `planned`：只有提示词和计划
- `generated`：已经生成，但未验收
- `accepted`：实际画面已验收
- `uploaded`：已上传到目标视频平台
- `bound`：已记录平台实际标签和唯一参考职责
- `rejected`：不进入视频阶段

只有 `bound` 状态能进入带引用的视频提示词。无引用的视频路线可以不建立资产状态，但不能暗示不存在的素材。

## 3. 资产清单

为每项资产记录：

| 字段 | 含义 |
|---|---|
| asset_id | 稳定内部ID，如CHAR-01、LOC-01 |
| type | character、location、prop、frame或edit |
| model | LIRA选择的目标图片模型 |
| prompt | 默认英文核心图片提示词 |
| ui_parameters | 画幅、质量、Soul ID等界面参数 |
| primary_role | 在视频中的唯一主要职责 |
| preserve | 必须继承的维度 |
| exclude | 明确不得转移的维度 |
| status | 当前阶段状态 |
| actual_tag | 用户确认的平台真实标签；未知时留空 |
| observed_notes | 对实际验收画面的观察或用户描述 |

## 4. 参考职责

常用主要职责：

- identity：脸、体型、年龄、服装和稳定标志
- environment：建筑、材质、地理和地标
- prop：形状、比例、材质和当前状态
- first_frame：首帧构图与空间占位
- motion：动作路径或节奏
- camera：摄影机路径或视场结果
- light：光源方向和曝光关系
- style：色彩、质感和视觉语域

每个目标维度只能有一个权威来源。一个资产可以拥有多个维度，但必须逐项写清；若多个资产争夺同一维度，先按用户要求和已验收程度确定唯一胜者。

风格参考不得覆盖身份、空间、动作和镜头。场景参考不自动继承原图机位；人物参考不自动提供动作；动作参考不自动改变身份和服装。

## 5. 上传标签

内部ID只用于项目管理，不能直接写进平台提示词。平台标签必须：

1. 素材已经实际上传。
2. 用户或平台明确给出标签。
3. 总控逐字记录，不翻译、不改大小写、不重排编号。

禁止根据上传顺序猜测`@Image1`，禁止把“准备作为第一张图”解释成已经获得`@Image1`。

## 6. 语言边界

- LIRA核心图片提示词：默认英文。
- 图片模型、参数、职责、风险和交接：默认简体中文。
- `xiaotian-CINEDANCE`最终视频提示词：默认简体中文。
- 用户提供的台词、标签和专名：原样保留。

不要先写整套英文视频提示词再翻译，也不要把英文图片提示词强行翻成中文导致模型锚点变化。

## 7. 组件加载顺序

完整路线严格按以下顺序：

```text
当前镜头需求
→ LIRA资产设计
→ 实际生成与验收
→ 上传与标签确认
→ 参考职责绑定
→ xiaotian-CINEDANCE视频编译
```

若任务在任何关口缺少真实外部状态，停在该关口并输出当前可交付成果。停止不是失败；用虚构状态越过关口才是失败。

## 8. 常见失败

| 失败 | 修正 |
|---|---|
| 图片和视频规则一次全部加载 | 先选路线，只读当前阶段组件 |
| 已有参考仍重新生成 | 直接进入视频路线 |
| 图片提示词后立刻写带标签视频提示词 | 等实际生成、验收、上传和绑定 |
| 把CHAR-01写进Seedance提示词 | 只使用平台真实标签 |
| 猜测第一张图就是@Image1 | 等用户明确标签 |
| 场景参考覆盖新镜头机位 | 只继承地理和指定维度 |
| 角色参考被视频提示词重新塑形 | 让已验收身份保持权威 |
| 生成结果与计划不同仍按计划交接 | 记录实际验收画面和偏差 |
