## 1. 核心公理

**表演是在压力下追求目标的行为，不是展示情绪。**

人物想从具体对象那里得到某种结果，外部或内部力量阻碍他，于是他采取策略。情绪是行动受阻或得逞后的副产品，不直接作为表演任务。

| 低质量指令 | 可执行的表演指令 |
|---|---|
| 他表现得很愤怒 | 他压低声音逼对方退回欠款，第一次要求失败后改用羞辱 |
| 她悲伤地哭泣 | 她锁住呼吸，把手机扣在膝上，护士靠近时重新抬起下巴 |
| 他紧张地看着门 | 他每听见一次走廊脚步就停止数钱，视线先抵达门缝，头部半拍后才转 |
| 她很有威严 | 她不抢话，回答前让沉默延长，占据桌子中央并触碰对方的文件 |

人物的身体不能只重复台词含义。真实表演允许语言和身体同时承载两种真相：道歉但仍在辩护，帮助对方但厌恶自己的帮助，嘴上拒绝却没有后退。

## 2. 场景的五个支柱

### 2.1 即时目标

目标必须是对具体对象施加的行动动词：

- 逼他承认撒谎
- 让她再等一周
- 诱使对方先动手
- 阻止孩子发现真相
- 证明自己并不害怕

不要使用“生气、愧疚、紧张、冷静”等状态词作为目标。状态不能直接表演。

### 2.2 阻碍与代价

阻碍可以来自：

- 对手追求相反结果
- 房间里有目击者
- 时间即将耗尽
- 自尊不允许人物求饶
- 人物不相信自己正在说的话

明确失败意味着什么。代价越具体，动作越紧：失去孩子、暴露谎言、被逐出团队、错过最后一次机会。不要把“场面会很尴尬”当作高代价。

### 2.3 策略

策略是人物此刻追求目标的方法：施压、讨好、羞辱、请求、挑衅、交易、威胁、拖延、转移话题、装作不在意。

策略失败后必须改变。整场只用一种语气和动作会形成扁平表演。

### 2.4 节拍

节拍是人物以同一种策略追求同一结果的最小行动单位。以下事件会结束当前节拍：

- 目标暂时实现
- 策略失败
- 新信息进入
- 权力关系改变
- 人物决定放弃或改变对象

每次节拍变化必须可见：动作停止、姿势改变、呼吸被锁住、说话速度变化、视线换目标、距离缩短或拉开。

根据可用时长限制数量：

- 3–5秒：一个动作状态或一个反应
- 5–7秒：一个核心行动与一次变化
- 8–12秒：两到三个清晰节拍

### 2.5 潜台词

潜台词不是额外表情，而是人物用错误的语言追求真实目标时自然泄漏出来的东西。可使用：

- 不是问题的问题
- 重复询问同一件事，说明不相信答案
- 在危险时刻开玩笑，掩护脆弱
- 突然改换话题
- 过短的回答，如“行”“随你”，用来关门
- 身体向前，嘴上却说“我不在乎”

不要命令人物“表演潜台词”。写真实目标和表面文本之间的矛盾即可。

## 3. 倾听与反应

表演的生命常在台词之间。

### 反应提前发生

人物通常在对方句子结束前已经理解意思。眼睛、呼吸或身体可以在关键词出现时开始反应，不要让脸一直空白，等对方说完才突然启动。

### 思考先于语言

困难问题之后保留微小评估时刻。人物先决定说真话、撒谎或沉默，再开口。统一速度的即时回答会像背词。

### 评估时刻

消息、侮辱、威胁或意外出现后，人物需要消化。近景可以只拍：视线短暂失焦、一次吞咽、呼吸停住、世界声音变远，然后才行动。

### 受对手感染

语速、音量和能量要回应对手。对方大喊，人物可以反喊，也可以突然降低音量迫使全场安静；但不能完全不受影响地继续上一种状态。

### 状态惯性

强事件发生后，身体不能下一秒恢复默认。呼吸、泪水、颤抖、伤痛、愤怒残留和注意力方向要继续影响下一个节拍及后续镜头。

## 4. 身体生活

### 4.1 先写身体，再写心理

为当前人物选择可见参数：

- 重心：高位、低位、偏前、偏后
- 节奏：快速破碎、迟缓沉重、缓慢经济、突然爆发
- 开放度：肩膀展开、手掌可见，或手臂交叉、下巴收紧
- 呼吸：浅快、低慢、屏住、鼻息加重、说话中断
- 头部：稳定、频繁确认、避开、先于身体转向

声音和身体必须一致。刚跑完的人不能用毫无呼吸负担的完整长句；受伤的人每次移动都要有保护和代偿。

### 4.2 手上事务

人物通常需要一个正在做的真实任务：修发动机、数钱、切面包、擦杯子、折纸、整理药盒。事务能：

- 给手部提供真实动作
- 填充有内容的停顿
- 显示人物如何控制局面
- 让动作停止成为标点

**中断动作原则：** 如果人物持续切菜，在听见一句话时刀停在砧板上，这句话就成为事件。停止比新增夸张动作更有力。

### 4.3 距离关系

人物距离是关系的可见图表：

- 0.5米以内：亲密或暴力；未经允许进入就是侵略
- 0.5–1.2米：私人信任区
- 1.2–3.5米：工作、警惕、谈判
- 3.5米以上：疏离、等级、公开对峙

距离改变等于节拍改变。明确谁主动靠近、谁后退、谁冻结不动，以及这个变化为何发生。

### 4.4 地位行为

高地位行为：头部稳定、动作少而慢、长视线、回答前停顿、占据空间、触碰他人物品。

低地位行为：忙乱、自我触碰、断裂说话、用笑填空、用眼神请求许可、不断调整位置。

最有价值的是地位破裂：老板有一瞬间露出恐惧，下属突然停止讨好。地位由行为表现，不由职位名称自动决定。

### 4.5 步态

如果人物在镜头中行走，为其步态命名并拆解重量、落脚、节奏、躯干、手臂和头部。示例：

- “旧拳手步”：短而经济的步子，整脚承重，肩线稳定，双手保持松弛准备
- “撞城槌步”：身体质量持续向前，脚跟重落，转向依靠整副躯干
- “展厅步”：脚步轻而精确，骨盆稳定，头部先确认观看者再改变路线

当触发事件出现时，说明步态怎样改变。不要只写“自信地走路”。

## 5. 语言与声音

- 节奏要准确，快速不等于含糊。
- 对话可以重叠，但关键词和剧情信息保持清楚。
- 真正危险的人常降低音量，让别人靠近听；大喊通常暴露控制力下降。
- 停顿必须包含评估、决定、拒绝或手上事务，否则就是空洞停顿。
- 真实语言允许打断、重复、半句话和没说完的结尾。

### 固定声音母版

每个长期角色建立一条固定声音描述，只在人物实际说话时原样使用：

```text
“一名[年龄]岁的[地域/口音特征]。[音色与音域]；[语速和表达方式]；[稳定情感底色，以及压力下怎样变化]。”
```

声音身份跨场景保持固定；当前表演只改变语速、音量、呼吸和断裂方式，不能让同一人物突然换成另一种声线。

## 6. 人物表演母版

长期角色可以建立一次150–220词左右的母版。母版不直接全量进入每条视频提示词。

固定顺序：

```text
角色表演身份：[姓名]。
[年龄、体型、姿态及身体传记]。
[驱动其身体行为的心理引擎]。
声音：[音高、音色、口音、语速，以及压力下如何变化]。
习惯与触发：[稳定习惯]；[压力习惯]；[掩饰行为]；[面具和裂开条件]。
眼神生命：[视线、眨眼、眼睛如何先于头部行动]。
步态：[命名步态与具体力学]。
然而，当[精确触发]发生时，[姿势、步态、面部和声音的具体变化]。
[可选：唯一真正让他软化的人、动物或物件]。
```

母版规则：

1. 只写可观察行为；每个内在状态都有身体标记。
2. 每个习惯动作都有触发条件，不能只是装饰。
3. 必须同时包含面具和精确裂开条件。
4. 可设置一个软化对象，不要设置多个。
5. 不写服装、摄影、色彩和灯光；这些属于当前镜头。
6. 体型与姿态要能读出职业、旧伤、生活史和自我形象。

## 7. 眼神生命

眼神生命在每个主要人物镜头中都是必需项：

- 视线有明确目标，并随注意力在对手、手、门、出口、道具之间微移
- 保持自然微扫视，不把眼睛冻结在单一点位
- 眨眼频率与状态一致：压力下短促成串，控制中缓慢稀少，解离时眨眼后短暂失焦
- 眼睛保持湿润、有真实眼神光，但不写成塑料般高亮
- 眼睛先抵达目标，头部和身体随后跟进
- 节拍改变时，视线稳定度、眨眼速度和落点也变化

克制静止必须是有意选择，不是死机。捕食者般少眨眼的人仍会缓慢移动视线，并用稀少、完整的眨眼作决定。

## 8. 当前镜头适配

每个镜头都要重写母版，而不是粘贴：

1. 只处理当前在场人物。
2. 保留身份、声音、稳定习惯、眼神方式和长期情感线。
3. 根据当前姿势、事务、时间、伤势和节拍重新表达。
4. 无法执行的行为转化能量出口，不直接删除。
5. 最终使用连贯的可拍摄语句，不在提示词里使用性格量表。
6. 有平台引用时，人物段以准确的 `@标签` 开头，防止表演错绑对象。

主角的当前镜头适配通常控制在80–140中文词；重要对手控制在50–100词；次要人物更短。复杂信息优先写入时间轴，而不是把人物介绍无限拉长。

## 9. 多人物表演

- 反应以波浪传播，不默认同步。
- 事件之后优先考虑目击者的反应画面。
- 群体持续有轻微生活动作，关键威胁生效时突然停止，形成“忙碌到静止”的标点。
- 所有穿越空间的动作都需要动机：靠近、逃离、遮住脸、夺取地位、阻挡出口或结束谈话。
- 强者通常更静、更轻；弱者通常更忙、更响。打破这一规律时要把它当作事件。
- 危险不靠慢动作转头和刻意狞笑预告；真正的暴力可以没有蓄势。
- 跨镜头的疲惫、伤痛、污渍和心理磨损逐步积累，不在每个镜头重置。

## 10. AI 表演故障与修正

| 故障 | 画面症状 | 提示词修正 |
|---|---|---|
| 表情示意 | 眉毛和嘴部夸张表现情绪 | 删除表情任务，补目标与手上事务 |
| 从开头演结果 | 第一秒已经知道结局 | 只写人物此刻已知的信息 |
| 等台词结束才反应 | 对手说话时脸为空白 | 让反应在关键词出现时提前启动 |
| 单一策略 | 全程喊叫或全程委屈 | 给每个节拍一个新行动动词 |
| 手势解释台词 | 说“大”就张开双臂 | 让手势领先思想、反驳语言或保持不动 |
| 免费情绪 | 没有触发就哭或爆发 | 建立克制到破裂的代价链 |
| 身体不符传记 | 疲惫人物动作像全新数字人 | 写重心、磨损、旧伤和代偿 |
| 威胁预告 | 狞笑、慢转身、刻意停顿 | 让威胁保持日常，让周围人承担恐惧 |
| 群体同步 | 所有人同时转头惊讶 | 根据注意力和利益错峰反应 |
| 情绪重置 | 强事件后立刻恢复默认 | 把呼吸、视线和动作残留带入下一节拍 |
| 近景过演 | 眼眉嘴持续剧烈运动 | 镜头越近，动作越少，只留眼神与思想 |
| 死眼 | 冻结凝视、无眨眼、玻璃感 | 写完整眼神生命和节拍变化 |

## 11. 表演强度检查

使用五级标准静默自检：

1. 木偶：只有台词，没有行为。
2. 朗诵者：展示情绪，身体解释语言。
3. 熟练者：目标可读，但策略单一、反应偏晚。
4. 活人：持续行为、策略对比、潜台词与文本分离、地位写进身体。
5. 磁场：达到“活人”，并同时表演两种真实且矛盾的力量。

主要人物镜头目标为第四级以上。若仍可以用一个单纯情绪词概括全部表演，继续改写。

交付前确认：

- 每个主要人物都有对具体对象的行动目标
- 阻碍与失败代价真实存在
- 节拍变化能从姿势、节奏、呼吸、视线或距离中看见
- 人物持续倾听，对手台词结束前可以开始反应
- 手上事务和动作中断具有意义
- 眼神保持微扫视、自然眨眼和明确落点
- 声音与身体状态一致，未说话人物嘴唇保持静止
- 使用明确状态而不是冗长过渡动作
