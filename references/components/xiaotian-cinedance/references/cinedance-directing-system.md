## 1. 当前镜头隔离

最终提示词是一份封闭的当前镜头文件。只允许出现这个镜头必须可见或可听的内容。

提取：

- 当前人物、动物、道具、车辆和场景
- 当前有效的 `@引用标签`
- 当前动作、对白、声音和时长
- 首帧、末帧、空间关系和运动路径
- 光源方向、天气、材质和连续性状态

清除：

- 场次号、剧本标题和集数标签
- 未出镜角色及其标签
- 旧提示词碎片、上一场摘要和废弃道具
- “和上次一样”“继续之前”“如上”等需要模型猜测的说法
- 只出现在过去对白中、当前并不出镜的人或物

不得发明 `@标签`。每个标签都必须对应用户当前提供且此镜头确实需要的参考。

## 2. 当前参考与身份锚点

### 人物参考

参考图是脸、体型、年龄、比例、服装和独特标志的权威来源。提示词只补当前动作必需的锚点：

```text
@标签：年龄 + 身份/体型 + 当前状态 + 当前可见特征 + 动作相关的手、伤势或道具。与参考保持一致。
```

不要用冗长面部解剖覆盖参考图。不要把不相关旧伤、关系说明和当前不可见道具写进去。

### 场景参考

场景参考默认控制：建筑、材质、地理、气氛、地标，以及用户要求继承的光向。它不自动控制新镜头的机位和构图，除非用户明确要求复刻原图视角。

### 道具、车辆和动作参考

- 道具：形状、比例、材质、损坏状态、手部接触
- 车辆：外形、标识、门窗状态、位置、损坏、运动和反射
- 动作参考：只提供被指定的动作、节奏或摄影，不自动转移身份、服装、场景或风格

为每个参考指定主要职责，避免多个参考争夺同一维度。没有职责的参考从当前提示词中移除。

## 3. 场景地图与首帧

有场景参考或多人物调度时，先在内部建立地图：

- 摄影机世界位置与朝向
- 前景、中景、背景
- 主要地标的位置
- 人物位置、移动路径和出入口
- 主光源方向
- 轴线和屏幕左右关系

### 首帧占位

除非用户明确要求空镜开场，第一帧必须立即包含镜头所需主体和可读空间关系：

```text
第一帧已经包含所有必要人物，并处于规定位置；人物之间的距离、朝向和视线关系立即可读。
```

避免先生成无用空景、随机风景插入或等待人物稍后出现。若用户需要极短建立镜头，第一帧仍应立刻提供必要地理或主体信息。

## 4. 空间调度、视线和地标

为每个重要人物写清：

- 画面位置：画面左侧、右侧、中央、左三分线等
- 世界位置：门内、桌北侧、汽车后门前等
- 景深层级：前景、中景、背景
- 与人物或地标的实际距离
- 身体朝向、头部方向、眼睛目标
- 移动方向与结束位置

使用物理语言：

- 距烧毁汽车不超过1米，一只手压住焦黑引擎盖
- 后背贴住砖墙
- 双脚站在树根围合区域内
- 站在出租车右后门正前方
- 身体朝向@HERO，眼睛锁定其左手中的钥匙

不要依赖“附近、旁边、周围、在区域内”等模糊词。

### 身体与眼睛分开控制

人物可以身体朝向门口，眼睛仍盯着对手。明确：

- 躯干朝向谁
- 头部何时转向
- 眼睛看向谁或什么
- 背部是否朝向摄影机
- 侧脸朝画面左侧还是右侧

对白时只有说话者为规定台词运动嘴唇；其他人物持续倾听但保持嘴唇静止。

## 5. 单镜头与受控多镜头

### 默认单一连续镜头

优先单镜头，因为它更容易保持身份、空间和动作连续。以下情况才使用多镜头：

- 用户明确要求切镜、蒙太奇、反打或插入镜头
- 一个机位无法清楚看见关键动作和关键反应
- 地理、动作细节和人物反应必须由不同视场分别承担
- 两个同时发生的情感事件需要不同角度

### 多镜头契约

明确每次切镜：

```text
镜头A：时长、第一帧主体、机位、空间、动作和表演任务。
硬切。
镜头B：时长、第一帧主体、机位、空间、动作和表演任务。
```

允许的切镜词：硬切、撞击切、匹配切、插入切、反打切、甩镜切。默认不使用淡出、叠化、交叉溶解和随机转场。

每次内部切镜保持：

- 相同的当前人物与场景地理
- 连续的屏幕方向、视线和身体朝向
- 相同的光源方向
- 服装、伤势、道具归属和手部状态
- 血、水、雪、泥、烟、火的累积状态
- 未完成动作的进度

切镜不能让人物瞬移、道具换手、伤势消失或动作重新开始。

## 6. 光学与视场结果

Seedance 对可见光学结果通常比摄影元数据更敏感。优先写拍摄距离、画面透视、背景压缩、焦点结果和环境可见范围；视场角数字作为增强锚点，不作为无法妥协的唯一控制。

### 内容与视场匹配

| 内容任务 | 建议视场结果 |
|---|---|
| 自然纪录式动作 | 约47°标准视场，自然人眼透视 |
| 环境动作、人物靠近摄影机 | 约84°广角，环境边缘保持可读 |
| 大尺度地理 | 约107°直线广角，边缘空间展开 |
| 中近景人物 | 约29°短长焦，背景轻度压缩 |
| 紧张特写 | 约18°长焦，眼睛锐利、背景融化 |
| 远距离窥视或观察 | 约8°超长焦，前景遮挡与强压缩 |

### 标准自然视场

```text
约47°对角视场，摄影机距人物3–5米，自然人眼透视；面部和身体比例自然，背景可读但不过度展开，没有明显广角变形或长焦压缩。
```

### 经典广角

```text
约84°对角视场，摄影机距前景人物1–1.5米；近处身体存在感更强，环境延伸到画面边缘，空间纵深清楚，建筑直线保持笔直，不出现鱼眼弯曲。
```

### 直线超广角

```text
约107°对角视场，摄影机距前景主体0.5–0.8米；前景明显放大，环境向四周展开，边缘到边缘保持空间可读，直线不弯成鱼眼。
```

### 短长焦人物

```text
约29°对角视场，摄影机距人物4–6米；依靠镜头覆盖获得近景而不是贴近人物，面部比例稳定，背景向人物身后轻度压缩并柔化。
```

### 经典长焦

```text
约18°对角视场，摄影机距人物6–8米；背景明显压缩并融成柔和色块，焦点集中在眼睛和关键面部区域，画面具有远处观察感。
```

### 超长焦观察

```text
约8°对角视场，摄影机距人物20–25米；背景被强烈压平，只有人物清晰，画面下方约三分之一由失焦前景遮挡形成远距离窥视感。
```

### 防止光学漂移

同一镜头只承担一种主要内容类别。不要在同一个连续镜头中同时要求紧密人脸、宏观地理和微距道具细节。需要不同类别时，用有理由的硬切分配独立视场。

广角镜头至少说明摄影机靠近、环境可见、空间展开和直线保持；长焦镜头至少说明摄影机远离、背景压缩、主体锐利和背景柔化。不要只写“超广角”“85mm”“电影镜头”。

## 7. 摄影机与构图

把摄影指令写成摄影师可执行的物理行为：

- 摄影机高度：地面、膝部、髋部、胸口、眼睛、俯视
- 摄影机距离及所在人物哪一侧
- 主体占据画面位置和大小
- 镜头从哪里移动到哪里
- 焦点从什么转到什么
- 手持的重量、呼吸和修正方式

示例：

```text
摄影机位于@MOTHER右前方约2.5米，略低于眼睛；她占画面左侧三分线，右侧保留护士走来的负空间。前4秒机位稳定，手机熄灭后才进行几乎不可察觉的缓慢推进。
```

### 手持

手持应体现摄影师身体：呼吸、肩扛重量、站姿变化、微小安定和人工修正。避免数字抖动、随机震颤、漂浮无人机感和未经要求的稳定器顺滑。

### 构图优先级

即使允许模型自由构图，也要保护：

- 主体画面位置
- 视线与身体朝向
- 地标距离
- 光源方向
- 关键道具和动作时点
- 选定的视场结果

## 8. 时间、物理与材质

### 时间块

按真实时长分配动作：

```text
0:00–0:03：位置、动作状态、表演策略、摄影机和声音。
0:03–0:06：触发、反应、策略变化、摄影覆盖和物理后果。
```

一个时间块只承担一个主要动作或变化。先确认人物在现实时长内能够完成，再写进提示词。

### 物理约束

所有身体和物件具有：重力、质量、惯性、摩擦、接触、重量转移、碰撞、后续摆动和材质延迟。

人物行走：脚跟接触、重量经过髋部转移、脚趾推离、身体质量落稳。

人物奔跑：真实地面接触、膝部抬起、对侧摆臂、躯干倾斜和不完全一致的步幅。

手持重物：手腕角度响应重量，起落有加速和减速，物体不在姿势间瞬移。

衣料和头发：在身体动作之后产生轻微延迟，不与身体完全同步。

液体：遵循重力、黏度、抛物线和接触残留；血液会黏附、滴落、涂抹、积聚和染色。

雪、烟、火、尘：遵循风向，在需要时分布于前中后景，并随时间在表面累积；热源与冷空气接触可产生热扰动。

禁止失重身体、无摩擦脚步、橡胶般CG动作、物体瞬移和游戏引擎式假物理。

## 9. 灯光与曝光

灯光是优先约束，不是装饰形容词。明确：

- 主光源是什么
- 从哪个方向来
- 摄影机位于光源哪一侧
- 人物哪一面处于阴影或轮廓光
- 背景亮度
- 曝光优先保护什么
- 允许哪些高光，防止什么失败

### 逆光模板

```text
人物保持在摄影机与较亮背景之间；摄影机位于人物背光侧。面部允许落入阴影，只由轮廓光、环境反弹、湿润高光和眼神光提供少量细节。画面按背景高光曝光，不使用平坦正面主光或美颜补光。
```

若角色表演依赖眼神，逆光仍需保留可读的低强度眼神光，但不能把整张脸补平。

不要用多个摄影师和影片名字代替光源、方向、比例、衰减和曝光说明。

## 10. 对白与声音

- 只有引号中的剧本台词可以被说出。
- 不增加临场发挥、旁白、字幕、角色姓名和画外音，除非用户要求。
- 未说话人物嘴唇保持静止，但眼神、呼吸和身体持续倾听。
- 干净对白需要时，环境声在台词下方轻微降低。
- 需要即时说话时，明确台词在主镜头前0.3秒内开始。
- 需要沉默包围台词时，为台词前后保留可执行的评估空间。

声音应支持表演：玻璃停止擦拭后，布料摩擦声也停止；危险生效时，群体动作声突然减少；刚跑完的人声带着呼吸负担。

前一句台词只用于情感连续、但说话者不应出镜时，写成：

```text
仅保留上一句声音语境，不形成视觉内容：“原台词”。
```

## 11. 连续性与上下文清理

跨镜头保持：

- 身份、年龄、比例、服装和伤势
- 场景地理、轴线、出入口和地标
- 道具归属、手部状态和损坏程度
- 光源方向、天气、湿度、血迹、泥土和烟雾
- 人物刚刚完成的动作、未完成动作和情绪惯性

续接必须依据实际验收视频或实际观察到的末帧。计划中的末帧不能冒充真实生成结果。无法查看素材时，明确依赖用户描述，不虚构已经观察。

## 12. 提示词密度与静默 QA

### 高密度区域

- 身份与参考绑定
- 首帧与空间
- 身体朝向、视线、手部和关键道具
- 表演触发、策略变化和摄影覆盖
- 时间、物理、光向和对白

### 低密度区域

- 参考图已经清楚表达的普通服装
- 不影响剧情的背景物件
- 装饰性形容词和重复质量词
- 通用负面列表

### 静默检查

输出前确认：

- 所有 `@标签` 都在当前镜头实际使用，没有旧标签
- 第一帧已经满足主体和空间要求
- 人物位置、距离、身体方向和视线清楚
- 摄影机站位和视场结果与内容任务匹配
- 关键表演变化在当前构图中可见
- 时间内动作可以完成，身体和道具有重量
- 多镜头的轴线、左右、光向、伤势和道具连续
- 只有规定台词被说出，没有多余人物、字幕或旁白
- 最终使用简体中文

如果任一项不成立，先修正提示词，不向用户输出检查过程。
