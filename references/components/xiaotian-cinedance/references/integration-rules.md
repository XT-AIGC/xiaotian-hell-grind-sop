## 1. 融合目标

新系统不是 ACTING 与 CINEDANCE 的简单相加。它要解决两个常见断裂：

- 表演写得细，但摄影机没有站在能看见表演的位置。
- 摄影写得精确，但人物只有“愤怒、害怕、悲伤”等结果性表情。

每条人物镜头必须建立这条因果链：

```text
目标与压力 → 策略 → 可见行为 → 对手反应 → 节拍变化 → 摄影覆盖 → 声音与物理后果
```

最终提示词只保留链条中可见、可听和会影响生成的部分。目标、阻碍和潜台词用于推导行为；当它们无法直接拍摄时，不要把抽象解释塞进成品。

## 2. 信息分层

### 长期角色层

长期表演母版保存：身体传记、稳定声音、步态、习惯动作、眼神方式、面具及其裂缝条件。母版只建立一次，跨镜头保持一致。

### 当前场景层

当前场景保存：即时目标、对手、阻碍、代价、策略序列、地位和距离变化。它只服务本场，不改写长期角色核心。

### 当前镜头层

最终提示词只写：当前姿势、正在做的事务、这一刻的眼神目标、呼吸、动作状态、一次或少数几次节拍变化，以及摄影机如何覆盖它们。

若长期习惯当前无法执行，转化其能量而不是删除。例如，习惯踱步的人被困在椅子上时，可将能量转为脚跟轻抬、膝盖微振或纸张边缘被反复折叠。

## 3. 表演如何驱动摄影

| 表演事件 | 优先摄影选择 |
|---|---|
| 人物隐藏真实反应 | 保持克制中近景，让眼神和手上事务同时可见 |
| 面具第一次裂开 | 极轻推进、焦点转移或更紧构图；不要提前推进 |
| 对手的话改变局势 | 反应在台词结束前开始；摄影机留在倾听者或及时切到倾听者 |
| 地位上升 | 人物减少动作、降低音量、占据空间；机位可稍低或允许其控制画面中心 |
| 地位崩塌 | 重心下沉、距离后退、视线失稳；构图让空间压迫人物 |
| 威胁真正生效 | 优先拍周围人的静止和延迟反应，不靠威胁者做夸张预演 |
| 关系距离变化 | 用实际靠近、退开、转身、坐下或站起表达；镜头保持距离变化可读 |
| 关键道具成为事件 | 手上事务停止、放下或改变重量；用插入镜头只在细节无法读清时 |

运镜不是独立装饰。没有表演或信息变化时，默认保持机位稳定，让观众观察人物。

## 4. 时间轴融合

每个时间块使用同一顺序：

1. 当前人物与位置。
2. 已经处于什么动作状态。
3. 触发信息或对手行为。
4. 可见的评估、策略变化或状态惯性。
5. 摄影机如何看见这一变化。
6. 道具、衣料、液体、脚步等物理后果。
7. 同期声音或对白。

不要写长串过渡动作。Seedance 更容易生成明确状态：

- 使用“手停在杯沿，指腹仍压着玻璃”而不是“伸手拿杯子又慢慢停下”。
- 使用“已经向前逼近一步，身体占住桌角”而不是“开始走过去试图威胁他”。

连续镜头中，后一时间块从前一块的真实末态继续。多镜头中，每次硬切都要保留人物、道具、伤势、湿度、光向、视线和动作进度。

## 5. 多人物优先级

按戏剧作用分配提示词密度：

- 主行动者：目标、策略、身体、眼神、声音和节拍完整。
- 主要对手或关键目击者：倾听、反应、地位和距离变化完整。
- 次要人物：只写能影响画面的一个明确行为与反应时点。
- 群演：除非推动事件，只写整体状态和错峰传播，不逐人建立母版。

群体反应呈波浪传播。第一个人发现，第二个人半拍后跟上，第三个人可能没有反应。只有故意设计的喜剧同步或纪律化动作才允许完全同步。

## 6. 冲突解决顺序

当规则互相竞争时，按以下顺序取舍：

1. 安全、权利、用户明确禁区。
2. 用户提供的身份、剧情结果、台词和参考绑定。
3. 已验收成片与实际观察到的连续性状态。
4. 动作可读性、空间关系和物理因果。
5. 角色目标、表演真实性和状态惯性。
6. 摄影、切镜和声音逻辑。
7. 灯光、风格、质感和装饰性细节。
8. 本 Skill 的默认模板。

低优先级内容不得悄悄破坏高优先级约束。若必须舍弃用户要求的镜头效果才能保证更高层约束，解释取舍后再改；最终提示词里不写解释。

## 7. 输出密度

详细不等于冗长。把篇幅集中在以下高风险信息：

- `@标签`与身份锚点
- 首帧占位
- 身体朝向、视线和屏幕左右
- 表演触发、倾听和策略变化
- 手和关键道具状态
- 时间、物理和切镜连续性
- 光向、曝光和对白边界

减少以下低价值内容：

- 参考图已经清楚呈现的完整服装复述
- 不影响动作的面部解剖和背景装饰
- 多个摄影师或影片名字堆叠
- “高级、震撼、电影感、史诗”等无物理含义的形容词
- 大型通用负面词列表

用期望状态为主，局部故障锁为辅。例如先写“面部保持在逆光阴影中”，必要时再补“无正面美颜补光”。

## 8. QA 契约

成品必须同时通过以下六个维度：

| 维度 | 通过条件 |
|---|---|
| 表演 | 人物在追求目标，行为受压力改变；不是展示情绪结果 |
| 倾听 | 未说话的人持续评估，反应可在对方台词结束前开始 |
| 空间 | 首帧、左右、远近、朝向、视线和地标距离清楚 |
| 摄影 | 景别、机位和运动能看见关键表演，切镜具有理由 |
| 物理连续性 | 重量、接触、惯性、道具状态、轴线、光向连续 |
| 输出 | 默认简体中文，只含当前镜头必要角色、标签、对白和声音 |

任何一个维度失败，都先修正提示词再交付。
