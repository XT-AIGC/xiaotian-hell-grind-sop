# 最终 Seedance 2.0 中文提示词模板

根据镜头复杂度删去空字段。简单镜头可以合并成自然段；多人、对白或多切镜保留标题。

## 标准结构

```text
【场景内容】
[只描述当前镜头可见、可听的事件和结尾变化。]

【当前参考】
[@标签：当前身份、状态、动作相关锚点；与参考保持一致。]
[只列本镜头实际使用的标签。]

【首帧与空间调度】
[第一帧已有哪些人物和道具。]
[画面左右、前中后景、实际距离、身体朝向、视线和地标关系。]

【角色表演】
[主行动者：当前目标通过什么行为呈现；手上事务、重心、呼吸、眼神和声音。]
[对手/目击者：如何倾听、何时开始反应、地位和距离如何变化。]
[只写当前镜头相关内容，不粘贴完整人物母版。]

【镜头与构图】
[单一连续镜头或受控多镜头。]
[摄影机高度、距离、机位侧、主体画面位置、视场结果、焦点和运动。]
[说明运镜或切镜由哪个表演/信息变化触发。]

【分段动作】
0:00–0:0X：[人物动作状态 + 触发/反应 + 摄影覆盖 + 道具/声音。]
0:0X–0:0Y：[策略变化 + 对手反应 + 摄影覆盖 + 物理后果/对白。]

【物理与连续性】
[重量、接触、惯性、衣料/头发延迟、液体/天气行为。]
[轴线、左右、光向、伤势、道具归属和动作进度。]

【灯光与曝光】
[主光源、方向、摄影机所在光侧、阴影/轮廓、背景亮度和曝光优先级。]

【对白与声音】
[只有规定台词；说话时点；未说话人物嘴唇静止。]
[环境声、动作声、音乐和字幕规则。]

【局部防错锁】
[只针对高概率故障写短锁，例如：不增加人物；第一帧不为空；无正面美颜补光。]
```

## 单镜头紧凑结构

```text
[场景与首帧]。[人物位置、朝向、视线和当前动作状态]。[表演目标转化出的具体行为、倾听和一次变化]。[摄影机位置、视场、构图，以及何时因表演变化而运动]。[时间顺序]。[物理、灯光、对白和声音]。[必要的局部防错锁]。
```

## 多镜头结构

```text
受控多镜头序列，只使用明确切镜。

镜头A｜0:00–0:0X
[第一帧主体和空间]。[表演任务]。[机位与视场]。[动作、声音和末态]。

硬切。

镜头B｜0:0X–0:0Y
[从镜头A末态继续的人物、道具、视线和光向]。[新的表演/信息任务]。[机位与视场]。[动作、声音和末态]。

连续性：[身份、左右、轴线、道具、伤势、湿度、光向和动作进度保持连续]。
```

## 使用规则

- 最终结果默认使用简体中文。
- `@标签`和精确台词按用户输入逐字保留。
- “人物目标与戏剧压力”可以用于内部推导；若直接写进成品，必须立即落到可见行为。
- 每个时间块同时包含表演和摄影覆盖，不把两者拆成独立长文。
- 局部防错锁只处理当前高风险故障，不追加通用负面词墙。
