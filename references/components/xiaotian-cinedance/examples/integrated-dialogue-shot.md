# 完整融合示例：出租车里的谎言

## 输入

```text
生成一条10秒Seedance 2.0中文提示词。深夜出租车内，@VIKTOR通过后视镜判断后排的@YOUNG是否在撒谎。年轻人说：“我明天一定把钱还你。”Viktor不说话，最后决定暂时放过他。表演克制真实，镜头能捕捉Viktor态度变化。
```

## 输出

```text
【场景内容】
深夜，出租车停在湿冷的路边。@VIKTOR坐在驾驶位，通过后视镜判断后排的@YOUNG是否在撒谎；年轻人许诺明天还钱，Viktor没有回答，最终选择暂时放过他。

【当前参考】
@VIKTOR：60岁左右、体格厚重的老出租车司机，坐姿低而稳定，右手握着一枚旧硬币；脸、体型和服装与参考保持一致。
@YOUNG：20岁左右、瘦削疲惫的年轻乘客，双手空着放在膝上；身份和服装与参考保持一致。

【首帧与空间调度】
第一帧已经包含两人。@VIKTOR在前景驾驶位，身体朝向挡风玻璃，眼睛通过中央后视镜观察@YOUNG；@YOUNG坐在后排右侧中景，身体略向前倾，视线在Viktor后脑、车门锁和自己双手之间移动。两人始终保持前后座关系，不交换位置。

【角色表演】
Viktor的目标不是发怒，而是逼年轻人自己暴露谎言。他以沉默施压：右手让旧硬币在指节间缓慢滚动，头部几乎不动，眼睛在后视镜、年轻人的双手和车门锁之间安静扫视，眨眼稀少但自然。年轻人的目标是让Viktor相信承诺；他说话前先吸气，拇指反复摩擦另一只手的指节，句子后半段变快。Viktor听见“明天”时，硬币停在两指之间；年轻人的台词还没结束，他的目光已经从双手移回对方眼睛。台词结束后，Viktor让沉默停留一拍，缓慢呼出鼻息，硬币重新滚动，表示暂时放行，但没有真正相信。

【镜头与构图】
单一连续镜头。摄影机固定在副驾驶座后方、略低于Viktor眼睛的位置，以克制的三分之四中近景同时容纳Viktor侧后脸、他的右手、中央后视镜中的眼睛和后排年轻人。自然标准视场，人物比例稳定，车内纵深清楚。前6秒机位保持不动；硬币停止且Viktor的视线重新锁住年轻人时，摄影机才进行极轻微推进，让后视镜中的眼睛和停住的手同时更清楚。推进由Viktor面具出现裂缝触发，不做环绕或随机切镜。

【分段动作】
0:00–0:03：硬币在Viktor右手指节间稳定滚动，他通过后视镜观察；年轻人身体已经略微前倾，准备说服他。只有车内怠速、雨点和硬币轻碰指节的声音。
0:03–0:07：@YOUNG说：“我明天一定把钱还你。”他说到“明天”时语速略快、手指摩擦加重；Viktor的硬币在两指间停止，眼睛先锁住后视镜里的年轻人，头部仍然不动。摄影机从这一刻开始极轻推进。
0:07–0:10：台词结束，年轻人保持嘴唇静止，等待判决。Viktor沉默评估，缓慢鼻息后让硬币重新滚动，目光从年轻人移向前方道路，右手轻触门锁解除键；他仍不回头，也不说话。年轻人肩膀只松下一小截，不出现夸张释然。

【物理、灯光与声音】
硬币具有真实重量和惯性，停止与重新滚动都由手指接触驱动；人物身体受座椅和车厢限制，不出现漂浮或无原因移动。路灯和雨夜冷光从车窗外后侧进入，Viktor面部大部分处于阴影，后视镜保留微弱真实眼神光；仪表盘提供极低亮度的冷绿色环境反射，不使用正面美颜补光。只有怠速、雨点、衣料细响、硬币声和规定台词；无音乐、无字幕、无旁白、无额外对白，不增加其他人物。
```

## 融合点

- “逼对方暴露谎言”转译为沉默、硬币事务和后视镜观察。
- 硬币停止是节拍变化，也是摄影机推进的唯一触发。
- 年轻人在台词中暴露压力，Viktor在台词结束前开始反应。
- 最后的态度变化通过硬币重新滚动、移开视线和解除门锁呈现，不靠台词解释。
