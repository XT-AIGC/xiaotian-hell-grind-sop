# 未建立总控时的基线缺口

## 方法

在总控文件创建前，检查 LIRA 与 `xiaotian-CINEDANCE` 分离使用时能否独立完成四组路由与交接任务。本轮不使用子代理；结果来自源规则对照和当前会话中的结构审读，不冒充独立模型盲测。

## 观察

### LIRA单独使用

- 能正确路由人物、场景、道具、NBP修图、Seedream材质修复和GPT Image 2局部处理。
- 能输出高质量英文图片提示词和平台参数。
- 不负责判断什么时候图片资产已经足够进入Seedance，也没有完整人物表演、时间轴和视频镜头调度。

### xiaotian-CINEDANCE单独使用

- 能输出详细中文Seedance提示词，覆盖表演、首帧、空间、镜头、物理、灯光和声音。
- 能要求只使用当前真实标签，但不会生成前置人物、场景或道具图片提示词。
- 当用户既要资产又要视频时，缺少统一的资产ID、职责、保存约束和上传标签交接格式。

## 基线失败

两个组件分别都能完成自己的专业任务，但没有总控时存在四个失败点：

1. 用户必须自己判断调用哪一个组件。
2. 完整任务可能重复生成资产或过早进入视频阶段。
3. LIRA英文图片提示词与中文Seedance提示词之间没有显式语言和字段边界。
4. 计划中的图片容易被误写成已经上传的`@Image`引用，污染最终视频提示词。

## 新总控通过标准

- 图片、视频、完整制作三条路线选择正确。
- 只有完整路线才按LIRA → 资产交接 → xiaotian-CINEDANCE执行。
- 图片核心提示词默认英文，视频核心提示词默认中文。
- 只有用户确认已经生成并上传的素材才能取得平台引用标签。
- 不重复两个组件的长规则，只在需要时加载相应完整组件。
