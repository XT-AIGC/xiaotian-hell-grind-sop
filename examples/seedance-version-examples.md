# Seedance 版本示例

以下为规则示例，不是模型生成记录。示例标签仅在对应用户输入明确确认后有效；不复制到其他任务猜测标签。

## A. 保留2.0 / 未指定版本

输入：平台已确认支持10秒生成，两张验收素材已上传，`@Image1` 是女主，`@Image2` 是走廊。写10秒中文Seedance镜头，女主敲门后等回应。

交接：目标 Seedance 2.0（未指定版本默认 2.0），视频直达；平台10秒生成已确认；不重新生成图片。若明确指定2.0，结果相同。

```text
【Seedance 2.0 中文视频提示词】
@Image1仅控制女主身份与服装；@Image2仅控制走廊地理、门的位置与材质，不继承原机位。首帧女主站在门外，身体侧向门，摄影机位于走廊同侧，以中近景看清她的手和侧脸。
0–3秒：女主抬手敲门两下，指节与门板真实接触。
3–7秒：手落回身侧，她屏住一次呼吸，眼睛看门缝，倾听门内动静；摄影机稳定。
7–10秒：没有回应，她缓慢呼气，视线仍留在门缝，肩膀稍松，不转身离开。
只有敲门、衣料和走廊环境声，无字幕、旁白或背景音乐。人物位置、门和光向连续。
```

## B. 显式2.5，30秒单次生成

输入：目标 Seedance 2.5；我已确认入口支持30秒生成。`@Image1` 女主、`@Image2` 会议室、`@Video1` 白模均已验收上传。白模控制空间、走位和摄影，会议室只控制材质与光线，女主控制身份。女主走进门、停步观察、走到空椅旁坐下，不说话。

交接：视频直达，30秒生成。白模不控制外观，会议室图不覆盖白模空间，女主图不覆盖走位。平台真实标签照录；无LIRA返工。

```text
【Seedance 2.5 中文视频提示词】
@Image1控制女主身份与服装；@Video1是白模，只控制空间布局、门与空椅位置、人物路径和摄影机轨迹；@Image2只控制会议室材质、色彩与光线，不继承人物外观、布局或机位。渲染为真实摄影质感，不保留白模材质。
单一连续镜头，摄影机沿白模已确认轨迹跟随，保持门、空椅和人物的相对关系。
0–6秒：首帧女主位于门口，身体朝向室内，轻推门并跨过门槛，目光先看前方空椅。
6–12秒：她停住半拍，视线扫过桌边，呼吸放慢，手从门把上松开；摄影机遵循白模的已确认轨迹，不另加推进或改机位。
12–20秒：她沿白模路径走向空椅，绕过桌角，目光回到椅背；步幅克制，脚下受力自然，不穿过家具。
20–26秒：她扶住椅背，将椅子拉开，转身坐下，手随后离开椅背，衣料与座面真实接触。
26–30秒：她调整坐姿，双手放在桌边，抬眼等待；紧张仍留在呼吸里，不突然放松成笑脸。
光向与桌面影子连续，保留脚步、开门、椅子移动与衣料声，无对白、音乐、旁白和字幕。
```

## C. 显式2.5，定点视频编辑

输入：目标 Seedance 2.5。平台时间戳视频编辑已确认支持，验收过的30秒源视频已上传为 `@Video1`。只把源视频12–16秒女主右手的动作改为整理袖口，其他不变。

交接：视频直达/编辑；时间原点为源视频开头，区间12–16秒；无新身份素材，不调用LIRA。

```text
【Seedance 2.5 中文视频编辑提示词】
编辑@Video1，时间码以源视频开头为0。仅修改12–16秒女主右手动作：右手轻捏左侧袖口，整理后自然放回原位。动作从12秒前的实际手位起，16秒前衔接回原视频下一段手位，不改变人物身体位置或剧情。
保留0–12秒与16–30秒内容；全片保留身份、服装外观、空间、其他人物、摄影机运动、光线、台词和声音。袖口变化仅限动作造成的自然褶皱，不改衣服设计。检查编辑区间两端动作、遮挡、阴影与音画连续性。
```

## D. 显式2.5，续接

输入：目标 Seedance 2.5；入口已确认可续接一次20秒。源片已验收上传为 `@Video1`，末帧女主坐在会议桌右侧，右手平放桌边，视线朝向门，紧张且沉默。继续等候20秒，不新增角色。

```text
【Seedance 2.5 中文续接提示词】
续接@Video1，新段从0秒计时，承接源片末帧。保持女主坐在会议桌右侧、右手平放桌边、视线朝向门，身份、服装、桌椅位置、摄影轴线和环境声延续。
0–6秒：她保持坐姿倾听，右手没有离开桌面，呼吸浅而慢。
6–12秒：她的指尖轻压桌面又松开，视线仍朝门，不改变身体朝向。
12–20秒：她缓慢呼气，坐姿仅轻微调整，继续等待；摄影机保持源片末机位，光向不变。无新增人物、对白、字幕、音乐或旁白。
```

新段在整片偏移从源片末尾计算。此处只给续接提示词；实际生成后先验收、上传、确认新源标签，再规划下一轮，不承诺无限续接。

## E. 能力未知 / 明确2.0超限

- 输入“Seedance 2.5，30秒，但不确定我的平台是否支持”：可交付30秒草案及待核对项，不能称可直接提交，也不猜API参数。若入口较短，按实际上限拆段。
- 输入“Seedance 2.0，30秒，一次生成”：保持2.0，解释单次15秒模型级边界，按平台已确认上限提供拆段方案；不得自动改2.5。比如两段各15秒，第二段需继承第一段实际验收的末状态，不能预造@Video标签。
- 输入“2.5素材还没上传，直接当@Video1编辑”：停在上传/绑定关；不引用猜测标签。即使编辑能力支持，真实状态关也不能跳过。
